# Criterios de evaluación de la evidencia

## 1. Clasifica cada referencia por diseño

| Código | Diseño | Herramienta de sesgo orientativa |
|---|---|---|
| GPC | Guía de práctica clínica / consenso | AGREE II |
| RS-MA | Revisión sistemática ± metaanálisis | AMSTAR 2 |
| ECA | Ensayo clínico aleatorizado | RoB 2 |
| COH | Cohorte (prospectiva/retrospectiva) | ROBINS-I / NOS |
| CC | Casos y controles | NOS |
| TRANS | Transversal | JBI |
| SERIE | Serie de casos / caso clínico | JBI / MINORS (quirúrgicas no comparativas) |
| DIAG | Precisión diagnóstica | QUADAS-2 |
| BASIC | Básico / cadáver / biomecánico / animal | — (evidencia indirecta) |
| OPIN | Opinión, revisión narrativa | — |

Si el diseño no se deduce de lo visible, márcalo `?` y no lo inventes.

## 2. Por cada referencia, anota (solo lo que conste)

- N y población; intervención/comparador; desenlace principal; seguimiento.
- Efecto principal con IC si aparece. **No recalcules ni redondees cifras.**
- Limitaciones visibles: tamaño, ausencia de grupo control, retrospectivo,
  centro único, conflicto de interés, desenlaces subrogados.

## 3. Juicio global (estilo GRADE, cualitativo)

Para el conjunto de evidencia sobre cada desenlace:

- **Riesgo de sesgo** (diseños predominantes).
- **Inconsistencia / heterogeneidad** (resultados en direcciones distintas, I² si consta).
- **Evidencia indirecta** (otra población, otra intervención, desenlace subrogado,
  estudios biomecánicos o en cadáver).
- **Imprecisión** (pocos eventos, IC amplios).
- **Sesgo de publicación** (solo si hay datos).

Certeza: Alta / Moderada / Baja / Muy baja. Es **tu valoración**, márcala como tal.

## 4. Separar evidencia de interpretación

- **Evidencia:** lo que reportan los estudios (con cita).
- **Interpretación:** lo que tú concluyes a partir de ello (sin cita, marcado).
- **Vacíos:** lo que no se ha estudiado o tiene muy baja certeza.

## 5. OpenEvidence como fuente

- Nunca se cita "OpenEvidence" en un manuscrito. Se citan los estudios primarios.
- La síntesis de OpenEvidence puede contener errores de atribución: comprueba que
  la cifra citada corresponde al estudio citado (al menos en las referencias clave).
- Para revisiones sistemáticas, OpenEvidence es **exploratorio**: ayuda a
  formular PICO y términos, no sustituye una búsqueda reproducible en
  PubMed/MEDLINE, Embase, Cochrane CENTRAL, Web of Science/Scopus y registros.
